# Acceptance Checklist — YTS Hub

## Product
- [ ] Landing page membantu pengguna mencari tindakan/informasi, bukan hanya mengenalkan organisasi.
- [ ] Search menjadi focal point hero.
- [ ] Unit, Program, Layanan, Event memiliki definisi dan route yang berbeda.
- [ ] Tidak ada data organisasi yang dikarang.

## Navigation
- [ ] Primary navigation konsisten.
- [ ] Mobile menu usable dengan keyboard/touch.
- [ ] Breadcrumb tersedia pada detail pages.
- [ ] Tidak ada dead-end page.
- [ ] Related action jelas.

## Landing Page
- [ ] Header
- [ ] Hero/search
- [ ] Quick access
- [ ] Layanan Populer
- [ ] Jelajahi YTS
- [ ] Program Aktif
- [ ] FAQ
- [ ] Aplikasi & Website
- [ ] Help CTA
- [ ] Footer

## Anti-Slop / Hallmark
- [ ] Tidak memakai generic purple gradient.
- [ ] Tidak memakai glassmorphism massal.
- [ ] Tidak semua section menggunakan grid card identik.
- [ ] Tidak ada pill/badge berlebihan.
- [ ] Tidak ada decorative blob/sparkle.
- [ ] Tidak ada fake statistic/testimonial/logo.
- [ ] Tidak ada arch, masjid, bulan-bintang, lentera, tasbih, kitab dekoratif.
- [ ] Typography hierarchy terasa intentional.
- [ ] White space konsisten.
- [ ] Icon set konsisten.
- [ ] Mobile memiliki composition yang sengaja dirancang.

## Accessibility
- [ ] WCAG 2.2 AA target.
- [ ] Keyboard navigation berhasil.
- [ ] Focus visible.
- [ ] Skip-to-content tersedia.
- [ ] Form labels benar.
- [ ] Search accessible.
- [ ] Accordion accessible.
- [ ] Reduced motion respected.
- [ ] Contrast memenuhi target.

## Performance
- [ ] LCP risk dievaluasi.
- [ ] JS hydration minimal.
- [ ] Font loading optimal.
- [ ] Images mempunyai dimensions.
- [ ] Tidak ada hero bitmap besar tanpa alasan.
- [ ] Build output diperiksa.

## Content Governance
- [ ] Published content punya owner.
- [ ] Review date tersedia.
- [ ] Status lifecycle valid.
- [ ] Archived content tidak muncul di search publik.
- [ ] Audit trail tersedia untuk perubahan penting.

## Search
- [ ] FAQ searchable.
- [ ] Service searchable.
- [ ] Program searchable.
- [ ] Unit searchable.
- [ ] Zero-result UX tersedia.
- [ ] Search result click dapat dianalisis.

## External Systems
- [ ] Link menunjukkan fungsi sistem tujuan.
- [ ] External destination ditandai dengan jelas bila perlu.
- [ ] Broken-link handling tersedia.
- [ ] Tidak ada secret di registry.

## Engineering
- [ ] Typecheck pass.
- [ ] Lint pass.
- [ ] Tests pass.
- [ ] Production build pass.
- [ ] Error/empty/loading states ada.
- [ ] No console error pada happy path.
